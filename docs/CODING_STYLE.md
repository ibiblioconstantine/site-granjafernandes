# Padrão de Código — Granja Fernandes

## Objetivo

Manter os arquivos de código do site legíveis, consistentes e **human friendly**, facilitando manutenção, revisão e futuras atualizações.

## Linguagens abrangidas

- HTML
- CSS
- JavaScript

## Padrão adotado

- Indentação com **2 espaços**.
- Não utilizar tabs para indentação.
- Arquivos em UTF-8.
- Final de linha em LF.
- Uma quebra de linha no final de cada arquivo.
- Remover espaços em branco desnecessários no final das linhas.
- Manter a estrutura hierárquica do código visível e consistente.
- Preservar o conteúdo funcional, os textos aprovados, URLs, caminhos de arquivos e referências de assets durante ajustes exclusivamente de formatação.

## Configuração do projeto

O repositório possui:

- `.editorconfig` para orientar editores compatíveis.
- `.prettierrc.json` como referência de formatação para HTML, CSS e JavaScript.

## Regra para novas alterações

Toda nova alteração de HTML, CSS ou JavaScript realizada no projeto deve manter este padrão de indentação e formatação.

Alterações de formatação não devem modificar conteúdo, comportamento, URLs ou assets sem que isso faça parte explícita da tarefa.

## Rastreabilidade

A padronização inicial de todo o código existente foi registrada na **Task 64** do controle do projeto.
