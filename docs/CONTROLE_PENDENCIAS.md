## Regra de atualização

Quando uma pendência for validada, atualizar o status e registrar a alteração em um commit do repositório.

Estados utilizados:

- **Confirmado** — informação aprovada para implementação/publicação.
- **Em revisão** — existe definição parcial ou depende de validação complementar.
- **Pendente** — informação ainda não fornecida/aprovada.

## Situação da V1

A primeira versão do site está publicada em GitHub Pages e utiliza HTML, CSS e JavaScript estáticos.

A implementação deve continuar somente com informações confirmadas. Itens pendentes ou em revisão não devem ser transformados em conteúdo definitivo sem nova validação.
