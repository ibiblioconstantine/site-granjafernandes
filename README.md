# Granja Fernandes — GitHub Pages v1

Versão estática da primeira implementação pública da Granja Fernandes — Ovos Caipiras.

## Publicação
- Branch: `main`
- Fonte do GitHub Pages: `/` (raiz)
- Arquivo de entrada: `index.html`
- Custom domain: `www.granjafernandes.com.br`
- O arquivo `.nojekyll` desativa a interpretação Jekyll para esta versão estática.

## Estrutura
- `index.html` — Home
- `nossa-historia.html` — Nossa História
- `nossos-ovos.html` — Nossos Ovos e Clube
- `receitas.html` — Receitas e Dicas
- `contato.html` — Contato, entrega e localização
- `404.html` — página de erro
- `assets/css/style.css` — estilos globais
- `assets/js/main.js` — navegação e links WhatsApp
- `assets/images/` — logo e imagem principal
- `assets/images/products/` — produtos
- `CNAME` — domínio personalizado
- `.nojekyll` — publicação estática sem Jekyll
